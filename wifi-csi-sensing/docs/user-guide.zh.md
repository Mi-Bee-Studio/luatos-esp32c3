# 感知节点用户手册（Sense Node User Guide）

[English](user-guide.md) | [中文文档](user-guide.zh.md)

**适用固件:** 0.1.0+ ｜ **硬件:** ESP32-C3 + 合宙 Air101 LCD（ST7735S 160×80）+ 5 按键

本手册面向日常使用者。项目定位见
[README.zh.md](../README.zh.md)。

---

## 1. 这是什么

一块**无摄像头**的 WiFi 感知终端：利用 WiFi 探测帧的信道扰动（CSI）判断
**房间里有没有人、在不在动、呼吸大概多少次/分钟**，结果显示在机身上的小屏，
精确分析由 PC 侧的 homepulse 引擎完成（经
serialtap USB 代理连接，见第 7 节）。

```
感知节点(本机) ──USB──> serialtap(日志+透传) ──> homepulse(PC 引擎) ──状态回传──> 小屏镜像
```

CSI 只反映无线信道的幅度/相位扰动，**不包含任何图像或语音内容**，也无法
还原具体动作细节——它只知道"信道变了"，隐私友好。

## 2. 上电与启动顺序

1. 插 USB 后屏幕点亮，显示 **SENSE NODE** 开机画面（约 2 秒）；
2. 自动进入 **Sense 页**；
3. 如已存 WiFi 凭据，自动连网（失败每 5 秒重试）；
4. 联网后自动开始 CSI 采集；若 PC 引擎在线，30 秒环境校准后进入跟踪。

## 3. 两个页面

**LEFT / RIGHT 键在三个页面之间循环切换（Sense → NET → SYS）。**

### Sense 页（默认，感知主页面）

| 区域 | 含义 |
|------|------|
| 状态卡片（描边随状态变色） | `* PRESENT` 有人（绿）／ `- ABSENT` 无人（灰）／ `CALIBRATING` 校准中（黄）／ `* PAUSED` 串流已暂停（黄，按 UP 恢复）／ `CAL IN Ns` 布防倒计时（黄，CENTER 长按触发）／ `NO SIGNAL` 无 CSI（未联网）／ `WAIT PC` 在采集但 PC 引擎未接入 |
| `BR 15.3 Q72%` | 呼吸率与置信度（**仅 PC 引擎在线时有精确值**；`BR -- local mode` = 本地粗估兜底；`unstable` = 信号不足被门控；布防期间显示 `needs empty room`） |
| `MOT ▓▓▓░ 42 walk` | 运动强度条（0-100）与分级（idle 静止 / light 轻动 / walk 走动） |
| 标题栏右侧 | `21Hz -46 PC`＝采样率 / 信号强度（dBm）/ 数据来自 PC（**PC 绿、本地黄、无数据灰**）；标题名右侧圆点 = 当前页指示（三页） |
| 底部悬浮条 | 动作回执 toast：按键动作触发后显示 1.5 秒（如 `STREAM OFF`、`CAL IN 10s`） |

### NET 页（网络与链路，v2.3 新增）

| 行 | 含义 |
|----|------|
| `WIFI SSID名` | WiFi 名称（整串显示，超长末尾省略号；`--` = 断网重连中） |
| `IP 192.168.x.x` | 本机地址（板端维护页 :80 就开在这个地址） |
| `LINK PC` / `LOC` | 数据来源：PC 引擎在线（绿）／本地自治（黄） |
| `STRM ON/OFF`（行尾右对齐） | CSI 串流状态（与 UP 键联动） |
| `RSSI -47 dBm` | 信号强度 |

### SYS 页（系统健康）

双列网格 + 底部快捷键速查行：

| 行 | 含义 |
|----|------|
| `UP 3h12m  HEAP 142K` | 运行时长 / 剩余内存 |
| `CSI 123k dr45` + `v0.1.0`（行尾） | CSI 累计包数 / 队列丢弃数（dr 持续增长才需要关注）/ 固件版本 |
| `FW v0.1.0  ESP32-C3` | 固件版本与芯片 |
| 底部暗色小字 | 五键速查：`L/R PAGE U STRM D DIAG L+R LCD` |

## 4. 按键（五键 + 长按 + 组合）

| 键 | 作用 |
|----|------|
| LEFT / RIGHT | 循环切换 Sense → NET → SYS 页 |
| UP | **暂停 / 恢复 CSI 串流**（全局有效）。暂停后 Sense 页大字显示 `* PAUSED`，激励 ping 停止，homepulse 面板会显示数据停更；再按 UP 恢复（沿用之前的采样参数）。适合临时静默设备或验证 PC 侧断链处理 |
| DOWN | **诊断快照**：把当前感知状态与 CSI 计数写成一行日志，进 serialtap 的日志流（现场排障时用来在时间轴上"打点"） |
| CENTER 短按（Sense 页） | **重新校准**（重学 30 秒环境基线，见第 5 节） |
| CENTER 短按（NET / SYS 页） | 诊断快照（同 DOWN） |
| CENTER **长按**（~0.7s，三页通用） | **布防 10 秒延迟校准**：倒计时显示在 Sense 页卡片上，走完自动开始校准——人按完键再走出房间即可；布防中再长按一次**取消** |
| LEFT + RIGHT **同按**（≥1s） | **息屏**（屏幕关显示，采集不受影响）；任意键**唤醒**。**空闲 10 分钟也会自动熄屏**（防屏幕残影），且熄屏期间每 1-5 分钟随机亮 1-60 秒——显示当前页数据或表情小动画；任意键随时唤醒 |

每个按键动作都有 toast 回执（屏幕底部悬浮 1.5 秒），按了什么一眼可见。

> 暂停期间 homepulse 会因数据断流显示设备离线/无数据——这是预期行为，不是故障；
> 恢复串流后 1–2 秒内数据回到面板。

## 5. 校准

感知阈值依赖环境（房间大小、家具、人与板子的相对位置）。**搬家、换插座
位置、大件家具变动后建议重校准**：按 Sense 页 CENTER 键，或点 homepulse
面板/托盘菜单里的"重新校准"。校准期间显示黄色 `CALIBRATING`，约 30 秒，
**期间房间里不要有人走动**（静止坐着没关系）。每次上电会自动校准一次。

**人在电脑前怎么离开房间再校准？** 三种"布防-离开"路径任选：
**CENTER 长按**（板上按键，布防 10 秒倒计时直接显示在屏幕上，再长按取消）、
homepulse 面板/托盘菜单或板端 Web（第 6a 节）里的**「离开后校准（60s）」**——
点一下然后走开，倒计时走完自动开始校准；反悔再点一次取消。板端 Web 最大的
优势是**手机可开**：人已经出了房间也能点。

## 6a. 板端 Web（手机/浏览器直接控制）

WiFi 连上后，板子自己就是一个小网站：浏览器打开 **`http://<板子IP>/`**
（IP 看 LCD **Node 页**），手机连同一 WiFi 即可访问。能做的事：

- **看状态**：有人/无人、动作、呼吸、采样率、信号，每 2 秒自动刷新
- **校准**：立即校准 / 离开后校准（60 秒布防，可取消）——**人在房间外
  用手机点**，彻底解决"校准要无人、按钮要有人"的矛盾
- **WiFi 配网**：扫描附近网络 → 选一个 → 输密码 → 连接（换网络不必接 USB）

注意：板端 Web 无密码，请只在家庭内网使用；连公网前请自行加反代鉴权。

## 6. WiFi 配网

凭据存在板子的 NVS 里，换网只需发一条 JSON。最省事的路径：**homepulse 面板
的「设备设置 · WiFi 配网」区**（点扫描、选网络、输密码即可），或**板端 Web**
（第 6a 节）。下面是手动方式：

**方式 A — serialtap 代理（推荐，板子不用拔）**

```bash
# 1. 开透传端点（守护进程已在跑的前提下）
serialtap proxy esp32            # 记下打印的地址，如 127.0.0.1:59085

# 2. 发送配网命令（bash 示例）
exec 3<>/dev/tcp/127.0.0.1/59085
printf '{"cmd":"wifi_connect","ssid":"你的WiFi名","pass":"你的密码"}\n' >&3
# 可选：先扫描周边 AP
printf '{"cmd":"wifi_scan"}\n' >&3
```

**方式 B — 任意串口终端**：115200 波特率打开板子串口，直接粘贴上面的 JSON 行。

连接结果看 Node 页或串口日志（`Got IP:` 即成功）。

## 7. 与 PC 组网（完整一套跑起来）

```bash
# 终端 1：serialtap 守护（USB 串口日志 + 透传代理 + 托盘）
serialtap run

# 终端 2：homepulse 感知引擎（自动发现设备；设备名是正则）
homepulse run -device esp32
```

- 浏览器观测：serialtap 面板 `http://127.0.0.1:8801/`（串口原始日志/事件流），
  homepulse 面板 `http://127.0.0.1:8799/`（感知状态 + 3 分钟曲线）。
- 两者的系统托盘图标颜色即感知状态（灰=断连/无数据，琥珀=校准，蓝=无人，绿=有人）。
- 只想让板子独立跑（无 PC）：什么都不用装，板子自动本地模式，功能有限
  （只有存在粗估，无呼吸精确值）。

## 8. 固件升级

```bash
serialtap flash esp32 \
  build/bootloader/bootloader.bin@0x0 \
  build/partition_table/partition-table.bin@0x8000 \
  build/esp32c3_info_display.bin@0x10000
```

serialtap 会自动暂停采集 → 调 esptool → 刷完自动恢复，全程在面板事件流可见。
刷写期间 homepulse 的会话会被短暂断开，属预期，它之后自动重连。

## 9. 故障排查

| 现象 | 原因与处理 |
|------|-----------|
| 大字 `NO SIGNAL` | 未联网，CSI 无从谈起。看 Node 页 WiFi 行；重新配网（第 6 节） |
| `WAIT PC` 一直挂着 | 板子在采集但 homepulse 没接上。确认 homepulse 在跑、`-device` 能匹配到设备名（serialtap `status` 可查） |
| `BR -- local mode` | 正常的本地兜底。想要精确呼吸值，启动 homepulse |
| `BR -- (unstable)` | 有人在动或采样率不足。静止 30 秒再看；确认 homepulse 配置 `stimulus_hz: 20` |
| 串口日志静默 1–3 分钟后自行恢复 | 已知现象：单核 ESP32-C3 在 CSI + 显示负载下的 USB CDC 瞬时停摆，板子侧自愈，非死机 |
| WiFi 反复重连 | 看日志里的 reason 码：202=找不到 AP（名字错/5G 频段？C3 只支持 2.4G），201=密码错 |
| Node 页 `dr` 数字疯涨 | CSI 队列溢出，通常是串口被外部工具占走导致流不出去；检查是否有别的程序直接打开了串口 |
| 屏幕显示错位/缺行 | v2.0 起有编译期防溢出断言，如仍遇到请附上串口日志中 `UI_COMMON: row overflow` 行报障 |

## 10. 摆放与有效距离（实测经验）

- **走动检测**：全屋级（同一房间内基本都能覆盖，板子与路由器之间不要隔承重墙）；
- **轻动作（挥手/起身）**：1–2 米内可靠；
- **静止呼吸**：最灵敏档，建议 2 米以内、板子与人在路由器同侧附近；
- 板子离路由器太远（RSSI < -70dBm）采样质量明显下降，优先保证板子—路由器链路质量。
